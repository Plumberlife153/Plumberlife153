# SEO & Visibility Guide for MGK Plumbing (mgkplumbing.com)

## Quick-Win Checklist (Do These First)

1. [ ] Claim/optimize Google Business Profile at [business.google.com](https://business.google.com)
2. [ ] Install Rank Math SEO plugin on WordPress
3. [ ] Fix domain — make mgkplumbing.com the primary domain (not .online)
4. [ ] Set unique title tags and meta descriptions on all pages
5. [ ] Add your phone number prominently on every page
6. [ ] Ask your last 10 customers to leave Google reviews
7. [ ] Enable SiteGround Optimizer for site speed
8. [ ] Submit your sitemap to Google Search Console

---

## 1. Fix Your Domain Setup (HIGH PRIORITY)

- **Use mgkplumbing.com as your primary domain**, not mgkplumbing.online
- In SiteGround: **Site Tools > Domain > Parked Domains** — set mgkplumbing.com as primary
- In WordPress: **Settings > General** — set both URLs to `https://www.mgkplumbing.com`
- A `.com` domain is more trusted by customers and search engines

---

## 2. Install an SEO Plugin (HIGH PRIORITY)

Install **Rank Math** (free, recommended) or **Yoast SEO** from the WordPress plugin store.

This lets you:
- Set custom title tags and meta descriptions for every page
- Generate an XML sitemap automatically
- Add schema/structured data (LocalBusiness markup)
- Get on-page SEO tips as you write content

## 4. Create Individual Service Pages (HIGH PRIORITY)

Create a separate page for each service instead of listing them all on one page:

- `/emergency-plumbing/` — Emergency Plumbing Services
- `/sewer-jetting/` — Sewer Jetting
- `/video-inspection/` — Sewer Video Inspections
- `/pipe-relining/` — Pipe Re-Lining
- `/water-filtration/` — Water Filtration Systems
- `/residential-plumbing/` — Residential Plumbing
- `/commercial-plumbing/` — Commercial Plumbing
- `/new-construction-plumbing/` — New Construction Plumbing

Each page should have:
- A clear H1 heading with the service name + location
- 300-500 words describing the service and benefits
- A call-to-action ("Call us at 803-448-6866" or a contact form)
- At least one photo of your team doing that type of work

## 5. Google Business Profile (HIGH PRIORITY — FREE)

This is the #1 way to get found by local customers:

1. **Claim/verify your profile** at [business.google.com](https://business.google.com)
2. **Complete every field**: name, address, phone, website, hours, service areas
3. **Set primary category** to "Plumber" + secondary categories ("Drain Cleaning Service", "Water Heater Installation Service")
4. **Add service areas**: Rock Hill, Edgemoor, Fort Mill, York, Chester, Lancaster, etc.
5. **Add photos weekly**: job sites, before/after, your truck, team — businesses with 100+ photos get 520% more calls
6. **Post updates weekly**: seasonal tips, promotions, completed jobs
7. **Ask every customer for a review** — send them a direct link after each job

## 7. Add Schema Markup (Structured Data)

Using Rank Math, add **LocalBusiness** schema to your homepage with:
- Business name, address, phone, email
- Service area and hours
- Reviews/rating
- License numbers

This helps Google show star ratings, phone number, and hours directly in search results.

---

## 8. Improve Site Speed

Use SiteGround's built-in **SiteGround Optimizer** plugin:
- Turn on GZIP compression
- Enable browser caching
- Minify CSS and JavaScript
- Enable lazy loading for images
- Convert images to WebP format

Test your score at [Google PageSpeed Insights](https://pagespeed.web.dev/) — aim for 80+.

---

## 9. Mobile-Friendly Checklist

Over 60% of plumbing searches happen on phones:
- [ ] Phone number is clickable (tap-to-call)
- [ ] Text is readable without zooming
- [ ] Buttons are large enough to tap
- [ ] Contact form works on mobile

- Install a free Let's Encrypt certificate
- Enable HTTPS Enforce

## 12. Set Up Free Analytics
